# 规则掠夺者 M11：五倍扩张方案

日期：2026-10-29
状态：设计评审稿（实施前置）
目标：在不否定现有 3 世界标准局的前提下，把完整一局的**地图、怪群、怪物机制、升级体系**扩张到当前版本的 5 倍以上体验量。

## 1. 当前基线（M10.2）

| 维度 | 当前值 | 说明 |
| --- | --- | --- |
| 完整一局 | 36 步 / 30 战斗房 / 800 杀 / 6–9 分钟 | 标准三世界 |
| 地图 | 800×800 = 0.64M px² | 固定单屏 |

| 事件 | 6 种，每局抽 2 | |

## 2. 五倍目标（可验收口径）

把「体验量」拆成四个必须同时成立的口径；任意一项不达标都继续改方案，不进入实现。

| 口径 | 目标 | 相对当前 | 验收方式 |
| --- | --- | --- | --- |
| 单局时长 | **35–45 分钟** | 5.4×（按 6.5 分钟中位） | 真人试玩 + 自动台账（非脚本清房时长） |
| 单局击杀 | **4,000–5,000+** | 5.0–6.2× | 结算 `kills`；fullrun/raidrun 归档 |
| 地图面积 | 新世界 **2400×2400 = 5.76M px²** | 9× | 相机滚动 + 小地图；截图/坐标断言 |
| 可成长等级容量 | **≥90 级**（4 规则槽 ×3 + 18 后期强化 ×3 + 8 律核 ×3） | 5×（18→90） | 构筑上限/HUD/奖励池断言 |

补充体验指标（不单独作为 5× 的分子，但必须显著增加）：

- 敌人：15 → **25+ 种**；新增 8 种基础 AI + 8 个精英词缀 + 3 个新 BOSS/小 BOSS。
- 房间：46 → **70+**；新增 18 个 2400×2400 大荒原战斗房 + 3 个 BOSS 房 + 3 个事件。
- 事件：6 → **12**；新增 3 个大荒原事件。
- 升级决策：每局约 30 次 → **55–70 次**（大荒原每房奖励 + 律核/高阶强化池）。
- 单屏压力：16 → **45 只**（轻量化杂兵 LOD；总量 10–14 波/房）。

**自检结论**：时长 5.4×、击杀 5.0×、地图 9×、升级容量 5×，四条硬口径全部 ≥5×；敌人种类不是 5×，但机制数量（15 种 AI + 8 词缀 + 新 BOSS）与怪物总量共同支撑“更多怪物机制”。方案达到要求，可以实施。

## 3. 产品结构：无界荒原（第 4 世界）

不推翻现有三世界，新增一个**终局大荒原**，让完整一局从 36 步变为 57 步：

- W1–W3 保持现有 10 + 13 + 13 = 36 步（10 分钟左右），负责教学、规则构筑、既有机制。
- **W4 无界荒原：21 步**（18 战斗 + 3 事件 + 最终 BOSS），全部使用 2400×2400 可滚动地图。
- 完整局：36 + 21 = **57 步**，18 个 W4 战斗房 × 180–220 杀 ≈ 3,600–4,000 杀，加上 W1–W3 的 800 杀，总击杀 **4,400–4,800**。
- W4 从第三世界通关后解锁；训练入口提供 `?start=3` / 调试直达，便于回归。

### 3.1 大荒原地图

- 2400×2400 世界，相机跟随玩家，带边界、地标、掩体群、可破坏物、三处“律核祭坛”。
- 每房 8–12 个地标/掩体，形成 3–4 条绕行路线；不再是一屏站桩。
- 小地图：右下角 160×160，显示玩家、敌人密度、祭坛、BOSS 方向；超出视野的精英/BOSS 用边缘箭头。
- 地形机制：荒原裂隙（周期塌陷）、风暴带（持续推挤）、律核矿脉（可交互，短暂增强）三选一轮换。

### 3.2 五倍怪群

- W4 每房配额 **180–220**，10–14 波，同屏上限 **45**；W4 总击杀 3,600–4,000。
- 新增“潮汐”节拍：每 3 波一次同侧大潮（一次压入 18–24 只），中间夹 2 波散兵；避免匀速刷怪。
- 轻量化杂兵 LOD：幼体/蜂群使用简化渲染（无血条/无光环/无预警圈），精英与特殊怪保留完整表现；目标 45 只同屏 ≥55fps（CPU×1），CPU×6 ≥30fps。
- 击杀总量与波次绑定，不靠加血；普通杂兵仍是 2–4 下死，保持割草。

### 3.3 新怪物机制（8 种基础 + 8 词缀 + 3 BOSS）

基础敌人：

1. **巢母**：固定产卵，定期孵出幼体；优先级目标。
2. **巢群幼体**：低血快速，纯怪潮填充；LOD。
3. **裂体**：死亡分裂成 2 只小裂体，逼迫清场顺序。
4. **壁垒**：给附近敌人 30% 减伤光环，必须绕后/点杀。
5. **潜地者**：钻地后从玩家脚下预警突起，迫使移动。
6. **重炮**：远距离曲射，落点提前显示，逼迫离开安全区。
7. **镜像**：复制玩家上一次位移方向，延迟发射同向弹幕。
8. **噬法者**：命中短暂降低攻速/移速，优先打断。

精英词缀（8）：自爆、护盾、召唤、吸血、狂暴、链接、传送、毒地。

BOSS/小 BOSS（3）：

- **巢母女王**（W4 中段）：产卵 + 三向酸液 + 召唤幼体。
- **壁垒巨像**（W4 后段）：旋转护盾段 + 冲撞 + 地面震波。
- **荒原吞世者**（最终）：三阶段 + 规则吞噬 + 地图裂隙 + 6 秒暴走。

### 3.4 更高阶升级体系

新增 **第 4 槽「律核」**（不占规则槽），并扩展后期强化池：

- 规则槽仍 3 条，但每条在升阶后可继续获得 **2 级律核强化**（规则等级仍是 Lv.3，额外“升阶等级”计入构筑容量；HUD 显示 `规则 Lv.3 ★★`）。=> 规则容量 9 + 6 = 15 级。
- 新增 **8 个律核** ×3 级 = 24 级：
  - 轨道刃、雷暴云、霜新星、火焰尾迹、猎杀标记、护盾回响、时间褶皱、血偿。
- 后期强化从 6 项扩到 **18 项** ×3 级 = 54 级；新增 12 项覆盖伤害、攻速、移速、范围、冷却、处决、护盾、拾取、连杀、减伤、贪婪、治疗。
- 总可成长容量：15 + 54 + 24 = **93 级**（当前 18 → 5.2×）。
- 每局奖励：规则/律核/后期强化/遗物/升阶/重铸/事件/祭坛，目标 55–70 次选择。
- 构筑 UI：新增律核槽、升阶星标、总等级 `x / 93`；奖励卡新增“律核”与“高阶强化”稀有度。

### 3.5 内容量

- 房间：46 → **70+**（W4 18 战斗 + 3 BOSS/祭坛 + 3 事件房）。
- 步数：36 → **57**。
- 事件：6 → **12**；新增 3 个大荒原事件：律核熔炉、荒原商队、裂隙赌局。
- BOSS：3 → **6**（新增 3）。
- 地图：W4 2400×2400（9× 面积），W1–W3 保留 800×800。

## 4. 技术方案

### 4.1 大世界渲染

- `RoomDef.arenaSize?: number`（默认 800，W4 为 2400）。
- `M0Scene` 用实例 `arenaSize` 替代硬编码 `ARENA`（约 50 处）；标准房按原逻辑缩放居中，大世界房 `scale=1`、相机 `setBounds(0,0,size,size)`、`startFollow(playerRoot)`。
- 新增大世界背景：平铺地板、地标、掩体群、可破坏物、小地图/边缘指示器；BOSS 全息图在 W4 隐藏或移动到地图中心。
- 现有 46 个房间不改坐标/逻辑，避免标准局回归；W4 使用数据驱动的新房间。

### 4.2 怪潮调度

- 复用 `WaveDirector`，扩展 `buildWavePlan`：waveCount 上限 14、maxAlive 45、gap 0.45–0.7；W4 使用“潮汐”组。
- 新增 `swarm` 标记：幼体/蜂群跳过 aura/warning/castRing 与血条，使用简化精灵与池化，降低 45 只同屏的渲染成本。
- W4 配额与波次由 `RoomDef` 数据驱动；压力测试以 45 只同屏为门禁。

### 4.3 敌人与 BOSS

- `EnemyKind` 新增 8 种；每种独立 `updateX` 模块（不继续堆在 M0Scene，新增 `src/game/enemies/`）。
- 精英词缀模块 `src/game/enemies/affixes.ts`，在 `spawnEnemy` 时附加词缀数据；伤害/死亡/受击钩子统一处理。
- 新 BOSS 模块 `src/game/bosses/brood.ts`、`bastion.ts`、`worldEater.ts`，沿用现有 `Host` 模式。
- 所有新增机制有独立单测/冒烟断言；BOSS 阶段有调试钩子。

### 4.4 升级体系

- `PlayerBuild` 新增 `core: CoreRef | null`；`CoreId` 8 个；`src/game/cores.ts` 纯数据 + 效果定义。
- 新 `CoreHost` 钩子：击杀、受伤、闪避、每帧、范围伤害；M0Scene 只做事件分发。
- `src/game/lateUpgrades.ts` 扩到 18 项；新增通用乘区，避免每项都写一段场景代码。
- 规则升阶星标：`RuleRef.mastery: 0|1|2`，通过章节/祭坛获得；只加数值/特效，不改变 Lv.3 上限。
- 构筑容量 `buildLevelSum` = 规则等级 + mastery + 律核等级 + 后期强化等级；HUD 显示 `x / 93`。

### 4.5 验收与性能门禁

- 单测：新增 cores、affixes、new enemies、W4 数据、升级池；目标 200+。
- 冒烟：大世界相机/边界/小地图、45 只同屏、8 种新 AI 各一条、3 个 BOSS 阶段、4 槽/律核奖励、W4 路线 57 步。
- fullrun：`raidrun` 57 步/4,000+ 杀；标准 fullrun 36 步不回归。
- 性能：45 只同屏 ≥55fps（CPU×1）、CPU×6 ≥30fps；大世界相机滚动无卡顿；2 分钟浸泡监听器 +0。
- 真人与真机验收仍为外部项，不用自动测试冒充手感完成。

## 6. 风险与对策

- **大世界重构破坏标准局**：用 `arenaSize` 默认 800 + 标准 fullrun 36/36 作为回归门禁；W4 独立房间数据。
- **45 只同屏掉帧**：LOD + 精灵池 + 减少每敌对象数；性能不达标就把 W4 同屏降到 36–40，仍保持总量 5×。
- **升级系统过度膨胀**：律核/后期强化用数据表 + 统一乘区，避免 90 个特判；先实现 8 核/18 项的最小效果集，再补特效。
- **57 步节奏过长**：W4 作为终局章节，可保存进度/分章节；标准局仍可在 10 分钟内完成。
- **内容重复**：W4 每房 3–4 条地形路线 + 潮汐 + 8 词缀组合，避免单纯放大。

## 7. 自检结论

四条硬指标（时长 5.4×、击杀 5.0×、地图 9×、升级容量 5.2×）均达到 5× 门槛；敌人/事件/BOSS 数量与机制数量显著增加但不是所有维度 5×，由怪群总量、地图探索与升级深度共同补足“体验感受量”。该方案可以进入实施。
