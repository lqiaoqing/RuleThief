# 《规则掠夺者》M0 可玩切片报告

> 日期：2026-10-25  
> 状态：**M0 完成，可实际游玩 3 分钟一局**。  
> 下一步：真人试玩调优；通过后进入 M1 规则组合系统。

## 1. 本阶段目标

按设计文档的 M0 + 首条规则切片，验证三件事：

1. 移动、闪避、自动攻击是否成立；
2. “看见敌人能力 → 击败它 → 夺走规则 → 攻击方式改变”是否成立；
3. 3 分钟一局的死亡、胜利、重开是否闭环。

## 2. 已实现内容

### 2.1 单局流程

- 倒计时 03:00；归零即胜利。
- 生命 100；归零即失败。
- 暂停 / 失焦暂停 / 继续 / 返回菜单。
- 失败与胜利结算：生存时间、击杀、掠夺规则数。
- 再来一局会完整重置 HP、计时、击杀、规则、敌人、弹幕、掉落物和临时特效。

### 2.2 玩家

| 项 | 当前值 |
|---|---|
| 生命 | 100 |
| 移动速度 | 185 逻辑单位/秒 |
| 自动攻击间隔 | 0.65s |
| 基础伤害 | 14 |
| 闪避冷却 | 4s |
| 闪避时长 | 0.18s |
| 闪避无敌 | 0.3s |
| 受击无敌 | 1.0s |
| 普通受击 | 屏震 + 红闪 + 击退 |

### 2.3 两种敌人

| 敌人 | 行为 | 数值 | 掉落规则 |
|---|---|---|---|
| 铁刺甲虫 | 接近 → 0.82s 预警锥 → 0.38s 高速冲锋 → 硬直 | 72 HP；接触 6；冲锋 12 | 爆裂 |
| 雷光蝠 | 保持 205–330 距离 → 0.55s 蓄力 → 发射雷击弹 | 46 HP；接触 4；雷击弹 8 | 弹射 |

- 敌人有独立 HP 条、受击闪白、伤害数字、死亡爆裂。
- 敌人之间会做简单分离，避免完全重叠。
- 波次压力随时间上升：最大同屏 5 → 7 → 9，生成间隔 3.2s → 2.8s → 2.3s。
- 每 10 击杀掉落一次生命碎片，恢复 12 HP。

### 2.4 规则掠夺

- 第一次击杀铁刺甲虫掉落「爆裂」碎片；第一次击杀雷光蝠掉落「弹射」碎片。
- 碎片自动飞向玩家，不要求玩家追着捡。
- 掠夺后立即生效：
  - 弹射：命中后 255 范围内跳跃最多 2 个不同目标，12 伤害。
  - 爆裂：命中点半径 74 范围伤害，7 伤害，不递归触发其他规则。
- HUD / 侧栏 / 手机构筑条实时更新；组合变为「雷暴连锁」。
- 规则槽、敌人图鉴、连击名、手机快捷条同步。

### 2.5 反馈与音频

- 命中：闪白、伤害数字、小火花。
- 爆炸：橙黄扩散、粒子、屏震、低频爆炸声。
- 弹射：青色闪电链、节点火花。
- 玩家受击：红闪、击退、低血量红色暗角。
- WebAudio 合成音效：射击、命中、爆炸、闪避、受伤、死亡、拾取、规则掠夺、胜利/失败。
- 环境音：低频 drone + 缓慢滤波 LFO；首次用户手势解锁。
- 声音开关：右上角按钮，状态写入 localStorage。

### 2.6 双端 UI

- PC：菜单、方形竞技场、顶部 HUD、右侧构筑/目标/图鉴/验证面板。
- 手机：竖屏 HUD、BOSS/目标条、构筑条、虚拟摇杆、闪避按钮、安全区适配。
- 横屏：竞技场按高度放大，摇杆/闪避分居两侧。
- 结算浮层覆盖全屏，PC/手机都可用。

## 4. 已知限制

- **尚未做真人 3 分钟平衡试玩**：数值是首版可玩值，不代表最终难度。
- 没有房间奖励、随机事件、精英、突变、三阶段 BOSS；这些在 M1–M3。
- 只有 2 种敌人；设计文档的 6 普通 + 2 精英尚未制作。
- 没有真机手机验收；触控手感/发热/低端机性能仍需测试。
- 音效与 BGM 是程序化合成，听感需由你试听确认；没有专业作曲。
- 结算截图使用调试数值；真实对局的时间/击杀会不同。

## 5. 下一步

1. **先试玩 M0 3–5 局**：记录死亡时间、死亡原因、规则获取时间、是否愿意再来一局。
2. 根据试玩调：
   - 敌人伤害/生成密度；
   - 基础 DPS 与敌人 HP；
   - 规则掉落时机与爆裂/弹射强度；
   - 治疗碎片频率。
3. 通过后进入 **M1 规则系统**：3 弹道 × 3 命中、9 组合、等级/替换、统一 AttackResolver 与单测。
4. M1 之后再接房间/奖励/6 敌人/精英/BOSS。

### 试玩时重点看

- 第一次冲锋预警是否看得懂、躲得掉。
- 第一只甲虫/雷蝠被击败后，规则碎片是否明显、掠夺后攻击变化是否立刻可感。
- 3 分钟是否太长/太短；后半段是否只剩重复刷怪。
- 手机竖屏是否能看清敌人、伤害数字和预警。
