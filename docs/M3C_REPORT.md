# M3c 事件房与分支路线报告

日期：2026-10-26
范围：4 种随机事件（每局 2 种）、分支路线选择、跨房修饰器、单局拉长到 9 步 / 13 节点。

## 1. 目标与完成情况

| 目标 | 状态 | 说明 |
| --- | --- | --- |
| 4 种事件 | 完成 | 血色祭坛 / 不稳定实验 / 遗忘神像 / 诅咒宝箱 |
| 每局 2 种 | 完成 | 构建 run plan 时随机抽 2 种不同事件，各占一个事件节点 |
| 分支路线 | 完成 | 4 个二选一节点；一局走 9 步，地图共 13 个节点 |
| 跨房修饰只影响下一房 | 完成 | 移速 +20% 在下一房生效，再下一房自动归 1 |
| 事件不与战斗混用 | 完成 | 事件房不产生敌人，选择后直接推进 |

## 2. 事件

| 事件 | A（风险） | B（安全） |
| --- | --- | --- |
| 血色祭坛 | 失去 20 HP，随机升级一条已装备规则（无可升级则回 20 HP） | 直接离开 |
| 不稳定实验 | 随机升级一条规则，下一房敌人移速 +20% | 回复 25 HP |
| 遗忘神像 | 随机把一条规则换成同槽另一条（Lv.1），回复 15 HP | 保留构筑 |
| 诅咒宝箱 | 下一房额外生成一个精英（不计配额），该房奖励 +1 张 | 不开启 |

- 所有事件都保证有一个「无风险」分支，风险分支立刻改变构筑或下一房压力。
- 事件会暂停场景与计时，界面显示当前生命，二选一后立即结算并推进。

## 3. 路线结构

一局 9 步、13 个节点：

| 步 | 内容 |
| --- | --- |
| 1 | 训戒前庭（战斗） |
| 2 | 二选一：余烬苗圃 / 孢子温室 |
| 3 | 二选一：回声回廊 / 蚀骨回廊 |
| 4 | 事件（从 4 种中抽 1） |
| 5 | 二选一：裂甲竞技场（精英）/ 灼热裂隙 |
| 6 | 菌毯回廊（战斗） |
| 7 | 事件（另一抽中事件） |
| 8 | 二选一：雷暴祭坛（精英）/ 焦土庭院 |
| 9 | 审判庭（BOSS） |

- 新增 4 个房间：蚀骨回廊（雷光蝠 + 爆裂甲虫）、灼热裂隙（史莱姆 + 爆裂甲虫）、菌毯回廊（孢子花 + 寒霜浮灵）、焦土庭院（铁刺甲虫 + 寒霜浮灵），规则池两两互补。
- 每局一定会遇到 2 个事件、最多 2 个精英、6 场战斗；单局约 10–13 分钟。

## 4. 实现要点

- `src/game/run.ts` 是纯数据层：事件定义、`buildRunPlan(random)`、`planNodeCount / planStepCount`。场景只按 plan 逐步推进。
- 场景状态机新增 `route` 与 `event` 两个状态；`loadStep` 负责分派到「路线选择 / 房间预览 / 事件」。
- 事件效果由 `EventEffect` 联合类型描述，`applyEventEffect` 统一执行；升级与更换规则复用 `applyBuildState`，因此会照常清理在飞弹体与状态。
- 跨房修饰器：`pendingSpeedMult / pendingBonusElite / pendingBonusCards` 在事件时写入，`beginRoom` 消费后立即清空；`roomSpeedMult` 参与刷怪时的速度计算。
- 诅咒宝箱的额外精英 `countsTowardQuota = false`，不影响清场配额，但房间仍需清空场上敌人才能结算。
- HUD 的 `ROOM n / 9` 直接取 plan 步数；事件步显示事件名与 `EVENT` 英文名。
- 调试钩子新增 `__RT_PICK_ROUTE__ / __RT_PICK_EVENT__ / __RT_OPEN_EVENT__`，plan 也暴露在 snapshot 里，便于自动化验收。

## 5. 验收

### 单元测试（69/69）

`rules` 19、`rooms` 23、`mutations` 12、`run` 12、`theme` 3。

run 覆盖：4 个事件各 2 选项、每个事件都有安全分支、风险分支效果与设计一致、9 步 13 节点、4 个分支节点、恰有 2 个不同事件、同局不重复房间、只引用真实房间、最后一步是 BOSS、固定随机源下可复现、不同随机源会产生不同事件组合。

### 浏览器冒烟（91/91）

生产构建，桌面 + 手机。关键项：plan 结构（9 步 / 13 节点 / 2 事件 / 4 分支）、路线覆盖层二选一并暂停、事件覆盖层二选一、冒险分支效果（失血 / 移速风险 / 换规则）、`+20%` 只作用于下一房、诅咒宝箱的额外精英与 +1 奖励卡、6 场战斗与 BOSS 三阶段、胜利 9/9、死亡 0/9、手机端路线与奖励流程。

### 性能

沿用 M3b 的测量方式：房间 1（19 敌人 + 5 处火焰）约 59fps，BOSS 三阶段约 60fps；事件与路线界面为静态 DOM，不影响帧率。

## 7. 已知边界

1. 路线是固定 9 步的「线性 + 二选一」，没有可视化地图，也没有回头路。
2. 事件只有 4 种，效果为一次性结算；没有事件链或后续影响。
3. 诅咒宝箱的额外精英不影响配额，但玩家必须清掉它才能结算房间。
4. 单局约 10–13 分钟，接近但未完全达到 15 分钟目标。
5. 仍未做真人试玩与真机验收。
