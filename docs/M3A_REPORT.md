## 4. 实现要点

- 敌人属性集中在 `ENEMY_SPECS`，场景的 `spawnEnemy` 完全由数据驱动（血量、半径、速度、精灵、尺寸、精英标记）。
- AI 用 `switch (kind)` 分派到 8 个更新函数；移动/远程通用逻辑抽成 `strafeAtRange`。
- 敌方弹体支持 `slowFactor / slowDuration`，命中时给玩家上减速状态；玩家移速在 `updatePlayer` 中相乘，闪避速度不受影响。
- 火焰地面是独立的 `hazards` 数组：有生命周期、淡出、按半径判定，切房时统一清理。
- 爆裂甲虫死亡在 `killEnemy` 中触发 `detonate`，只伤害玩家、不伤害其他敌人，避免连锁爆炸造成的不可读局面。
- 图鉴改为 `setRoomEnemies(kinds)` + `renderCodex(acquired)`：换房时切换敌人列表，获得规则时刷新"已掠夺"。

## 5. 素材

4 个新敌人用既有 Blender 管线生成（`scripts/blender/make_sprites.py`）：

- 孢子花：球茎 + 7 片花瓣 + 发光孢子核心 + 漂浮孢子。
- 灼焰史莱姆：胶质球体 + 顶部火焰锥 + 内部余烬 + 底部液面。
- 寒霜浮灵：倒锥斗篷 + 冰晶王冠 + 光环 + 下半身冰棱。
- 爆裂甲虫：甲虫壳体 + 背部 3 个发光囊 + 引信火花。

渲染参数：Cycles CPU 32 samples、512² 透明底，Pillow 统一裁切描边后输出 256²。可单独重渲：

```bash
ONLY=SPORE "/d/QSoftware/Programs/Blender Foundation/Blender 5.2/blender.exe" \
  --background --factory-startup --python scripts/blender/make_sprites.py
python scripts/postprocess_sprites.py
```

首轮渲染中爆裂甲虫的三个发光囊过大、位置偏前，读起来像一张脸；调整后把囊缩小并移到背部中线，同时降低自发光强度。

## 8. 已知偏差与边界

1. 精英的「保底突变天赋」尚未实现，暂时用四选一奖励替代。
2. 同屏上限仍是每房 5–8 只，没有做 30+ 单位的压力测试与对象池。
3. 敌人的难度曲线靠配额与配比，没有随时间或玩家 DPS 动态调整。
4. 单局约 6–8 分钟，仍短于设计目标；分支路线、事件房、商店未实现。
5. 火焰地面与冰霜减速的组合强度未做真人验证。
